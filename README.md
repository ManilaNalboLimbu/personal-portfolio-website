# DigiManila Portfolio

A modern Next.js and Tailwind CSS portfolio website for DigiManila.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Vercel Deployment

Vercel can deploy this project with its default Next.js settings:

- Framework preset: Next.js
- Build command: `npm run build`
- Development command: `npm run dev`
- Output directory: `.next`

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: create a production Next.js build
- `npm run lint`: run ESLint
- `npm test`: build and run a lightweight project smoke test
